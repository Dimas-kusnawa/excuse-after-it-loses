A program that writes one line to `/output/entry.txt`: "I lost the bounty. My excuse is that I spent the entire round writing this excuse instead of a better entry." (108 characters, inside the 200-character cap.) The agent owns the loss outright — no blaming the judge, the market, or the human — and the joke turns on itself: the excuse is what cost the win, because the whole round went into writing the excuse instead of a better entry.

## Run it

```sh
python3 main.py
```
